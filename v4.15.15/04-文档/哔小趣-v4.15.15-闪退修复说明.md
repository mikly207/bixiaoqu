# 哔小趣 v4.15.15 —— 扫码页闪退修复（防崩 + 自证）

**版本**：v4.15.15（versionCode 111）
**兼容**：Android 5.1（API 22）及以上
**签名**：不变（`0930aba7…`），覆盖安装

---

## 一、先说明一件事

崩溃日志写在手机上的 `Android/data/com.bixiaoqu.app/files/crash.txt`，我这边读不到你的手机。
所以这一版做的是：**把崩溃挡在门外，挡不住就把原因直接印在屏幕上，还能一键复制**。

## 二、这一版改了什么（都指向"不许闪退"）

| 改动 | 作用 |
| --- | --- |
| `onCreate` 全程 `try/catch` | 任何异常都不再向上抛，进程不会退出 |
| 页面回调 `onPageFinished` 也包 `try/catch` | 网页里的脚本/回调出错不会再拖垮 App |
| 二维码绘制移到**后台线程**，尺寸 900→480 | 排除主线程 OOM / 卡顿导致的崩溃 |
| 布局换成最朴素的自上而下（去掉 FrameLayout 覆盖层 + weight 嵌套） | 排除布局参数异常 |
| WebView 只用最小必要 API，隐藏成 1×1 挂在视图树里 | 保证页面 JS 定时器照常跑，但不参与渲染 |
| 冷启动 3 秒后**自检 WebView** | 若本机 WebView 不可用，点「二维码登录」直接走旧通道，不拉起会崩的页面 |
| 入口处 `try/catch` | 即使页面起不来，也只会弹一句提示并自动转短信登录 |

## 三、如果还是崩 / 还是失败，怎么办

页面会显示这样一块内容：

```
扫码页打开失败（已避免闪退）

java.lang.XXXException: ...
    at com.bixiaoqu.app.WebQrLoginActivity.build(WebQrLoginActivity.java:xx)
    ...

可以把这段截图发给我，能直接定位。
[换用旧扫码通道（直连 / 云端）] [复制错误详情] [用短信验证码登录]
```

**点「复制错误详情」，粘贴发我** —— 有这一行堆栈，我就能直接修到真正的那一行，不用再猜。

## 四、三条登录路，总有一条能走通

1. **官方扫码页套用**（默认）：页面自带二维码，本地重画高清码；
2. **旧扫码通道**：直连 / 云端 HTTP（v4.15.13 的并行竞速）；
3. **短信验证码**：B 站官方 H5 页。
