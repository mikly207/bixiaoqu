# 哔小趣 v4.55.0 · 功能大更新版

> 本版包含 **直播三大优化 + 小游戏精美重做与联机 + 内置名著离线阅读 + 留声机视频转 MP3** 四大块，平板 / 手机双端同步更新。

---

## 一、直播优化（放大 / 画质 / 加载）

### 1. 新增「放大直播内容」
- 播放时**双击画面**：1× ↔ 2× 快速放大 / 还原。
- **双指捏合**：1× ~ 4× 无级缩放。
- 放大后**单指拖动**平移画面；切房间 / 进全屏自动复位，不会错乱。
- 原有「铺满 / 适应 / 小窗」与「全屏」照常可用。

### 2. 画质开关终于真正生效
- 根因：旧版用 `platform=h5` 取流，`qn` 参数不生效、且只取单一 HLS，三档画质拿到的是同一条流，所以「切了没变化」。
- 修复：改用 B 站现行 `getRoomPlayInfo` 接口，请求真实清晰度档位，拿多 CDN 线路的 m3u8 交给代理竞速。
- 画质按钮现在显示**该房间真实画质**（如「超清 720P」「原画 1080P」），不再是个摆设。
- 档位改为：标清 / 高清 / 原画（房间不支持时服务端自动回退到最接近档）。
- 保留旧接口兜底，接口波动也不会打不开直播。

### 3. 端口与加载提速
- 播放列表改为**多线路并行竞速**（谁先返回谁胜出），首屏不再串行等待慢线路。
- 竞速用独立线程池，与转发池隔离，避免互相占满导致卡顿。
- 保留线路亲和 + 短缓存 + 断点熔断等既有优化。

## 二、小游戏精美重做 + 联机

### 1. 整体视觉升级（10 款全部受益）
- 新增统一精美视觉层：**竖向渐变背景 + 流动柔光光晕 + 纵深网格**。
- 游戏配色主题化：贪吃蛇（翠绿）、俄罗斯方块（靛蓝）、斗地主（墨绿）、植物大战僵尸 / 保卫萝卜（草绿）、五子棋（玉石绿）等各配专属色调。
- HUD 换成半透明胶囊 + 高光描边 + 金色「★ 最高分」。
- 结算面板：柔和遮罩 + 发光标题 + 渐变「再来一局」按钮。

### 2. 五子棋：三种对战模式（长按画面切换）
- **人机对战**：保留原有 AI。
- **本地双人同屏**：两台玩家轮流在同一设备落子。
- **局域网联机**：无需服务器、无需流量，两台设备连同一 WiFi 即可对战。
  - 入口：长按棋盘 → 局域网联机 → 创建房间 / 发现房间列表 / 手动输入 IP。
  - 主机执黑、加入者执白，落子与胜负实时同步。
  - UDP 广播发现 + TCP 直连，纯 Java 实现。

> 说明：联机功能落在最适合回合制的五子棋上；其余 9 款为单机精修版。

## 三、小说吧：内置经典名著，离线可读

- 书城顶部新增「**经典名著 · 内置全文 · 离线可读**」板块。
- 内置 5 部公版著作：**西游记、红楼梦、三国演义、水浒传**（四大名著）+ **鲁迅作品集**（《孔乙己》《故乡》《药》）。
- 专用阅读器：章节切换、字号调节（A±）、三档护眼（白 / 米黄 / 暗）、字体优化，翻页流畅。
- 完全离线，无需书源、无需联网；均为进入公有领域的经典，节选章节供阅读。

## 四、留声机：视频转 MP3 播放

- 留声机顶部新增「**视频转MP3**」按钮。
- 选择任意本地视频 → 提取音轨 → LAME 编码为 MP3（192kbps）→ 自动加入曲库并播放。
- 转换在后台线程进行，带进度显示；输出保存在应用私有音乐目录，可长期保留。
- 复用已有 pure-Java 解码/编码链路（MediaExtractor + MediaCodec + jump3r/LAME），不依赖外部服务。

### 快速体验
1. **直播放大**：进任意直播间 → 双击画面 / 双指捏合；画质按钮看真实清晰度。
