# 哔小趣 v4.65.0 · 滑动跟手与评论头像版

基于 v4.64.0，本版重点解决**底栏滑动卡顿**，并新增**评论区点头像进主页**。

---

## 一、底栏滑动流畅度重做（核心）

### 卡顿根因
v4.62~v4.64 的液态玻璃底栏，手指滑动时的链路是：

```
ACTION_MOVE → onHover → previewTab → styleNav → setActiveSlot(动画)
```

每次 `ACTION_MOVE`（每秒几十次）都会：
1. `cancel()` 掉正在跑的 240ms 吸附动画，再 `new` 一个 ValueAnimator 重头开始 —— 动画永远到不了目标，视觉上就是**跟手迟滞、一顿一顿**；
2. `onDraw` 每帧 `new` 出 9 个 `LinearGradient`（主体染色/受光/暗边/侧光/水珠三层/描边）—— 高频 GC 抖动；
3. `styleNav` 每次都遍历重设 5 个 tab 的图标与文字颜色 —— 重复开销。

### 修复方案
| 改动 | 说明 |
|---|---|
| **水珠直接跟手** | 手指按下/滑动期间，水珠位置由 `followFinger(x)` 按手指浮点位置**直接计算并绘制**，完全不启动动画；只在松手时做一次 230ms 平滑吸附到整数格 |
| **动画短路** | `setActiveSlot` 增加「已到位」「正朝同一目标动画」判断，避免重复 cancel/new 与无谓重绘 |
| **渐变缓存** | 新增 `ensureShaders`，所有 `LinearGradient` 只在尺寸或主题变化时重建，滑动期间零分配 |
| **颜色/位置解耦** | `styleNav` 只管颜色；水珠位置完全由底栏内部管理，程序化切 tab 时单独调用吸附（靠短路避免冲突） |
| **亚像素门限** | 只有水珠位置变化超过 0.002 格才 `invalidate`，过滤无效帧 |

效果：滑动跟手即时、吸附顺滑，消除掉帧与抖动；底栏在弱机上重绘负载显著下降。

## 二、评论区点头像进主页

- 主评论头像、楼中楼回复头像现均**可点击**，点击后打开该评论者的 B 站个人主页（复用已有 `UserActivity`，传入 `mid / 昵称 / 头像`）。
- 无 `mid` 的用户点击给出「暂无主页信息」提示，不跳空白页。
- 不影响原有的点赞、回复、表情面板等交互。
