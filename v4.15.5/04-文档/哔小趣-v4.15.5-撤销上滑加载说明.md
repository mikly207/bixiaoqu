# 哔小趣 v4.15.5 — 撤销「上滑加载下一批」

版本：4.15.5（versionCode 101，可直接覆盖安装，签名证书不变）

## 本次改动

按用户要求，**彻底撤销 v4.15.4 的「上滑加载下一批」功能**，首页恢复上一版行为（顶部下拉刷新换一批）。

已删除的相关代码（dex 验证全部清除）：
- 底部 footer（"↑ 上滑加载下一批 · 点这里也可以"）及其点击事件
- 底部提示浮层（"松开加载下一批"）及其上滑手势蓄力/触发逻辑
- `appendRecommend()` / `collectNew()` / `atBottom()` / `hideLoadMoreTip()` 四个方法
- 相关状态字段（`loadMoreTip` / `loadingMore` / `bottomArmed` / `bottomStartY`）

## 保留项

- **二维码登录修复**（v4.15.4 的核心 bug 修复）完整保留：轮询状态码改读 `data.code`（顶层 code 恒为 0 是旧版登录永远失败的根因）。
- 推荐条目解析的 `parseRec()` 公共方法保留（纯重构，行为与上版完全一致，减少重复代码）。

## 验证

589 个 class，与 v4.15.3 一致；上滑功能相关方法与文案在 dex 中全部不存在；二维码修复代码在源码中确认保留；签名校验通过、证书不变。
