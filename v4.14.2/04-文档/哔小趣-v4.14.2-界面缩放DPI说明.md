# 哔小趣 v4.14.2 —— 设置中新增「界面缩放 / DPI」

## 本次改动

在「设置 → 外观」中新增 **「界面缩放 / DPI」** 选项，方便在手表、小屏或其他设备上获得更合适的界面大小。

### 选项（3 个推荐 + 1 个自定义）
| 档位 | 说明 |
|---|---|
| 标准 · 100% | 跟随系统原始密度（默认） |
| 紧凑 · 85% | **手表 / 小屏推荐**：元素变小，一屏显示更多内容 |
| 宽松 · 120% | 元素更大、更好点按 |
| 自定义… | 输入 50~200 的百分比，精细调节 |

选好后自动重启应用，让所有页面按新密度重新构建，立即生效。

## 实现方式
- 本项目所有尺寸都是代码计算的 dp 值（`px = dp × density`）。因此只需在进程内按倍率调整 `DisplayMetrics.density / densityDpi`，**全 App 所有页面**（自绘 View、图标、列表、字号、间距、弹幕、播放控件）会等比缩放，无需逐个改动。
- 在 `BxqApp.attachBaseContext` 最早期锁定系统原始密度基准并应用倍率，保证第一个界面拿到的就是缩放后的值。
- 注册 `ActivityLifecycleCallbacks`，每个 Activity 创建时兜底再应用一次，防止部分机型在配置变化时重置密度。
- 应用是**幂等**的：已是目标密度时直接跳过，不会重复叠加。
- 倍率存本地（`ui_scale`，50~200），重启后保持。

## 使用提示
进入「我的 → 设置 → 外观 → 界面缩放 / DPI」选择档位或自定义百分比。手表端建议先试「紧凑 85%」；如果觉得字太小，再调回 100% 或调大。切换后应用会自动重启，属于正常现象。若某个页面显示异常，把百分比调回 100% 即可完全恢复系统默认。
