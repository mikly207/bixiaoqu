# 哔小趣 v4.15.3 更新说明

版本：4.15.3（versionCode 99）｜证书不变，可直接覆盖安装

## 一、修正玻璃"塑料感"

**根因**：旧版玻璃用 70%+ 不透明的单色渐变 + 偏亮描边，看起来是一块实心塑料盒，而不是玻璃。

**修正**（统一作用于设置页 / 搜索页 / 关注动态卡片 / 历史词条 / 分段栏）：
- **大幅降低染色浓度**：深色卡片主体 alpha 从 ~0xB2 降到 ~0x3D（约 70%→24%），背后内容能透出来；
- **多色受光层次**：改为「顶部柔光 → 通透主体 → 底部略沉」三段渐变，模拟玻璃体积感，而非一整块均匀色；
- **描边收细降亮**：从 0x2E 降到 0x14，只在顶缘留一缕高光，去掉"画了个框"的塑料感；
- 分段切换栏（全部/视频）改用同一个 `GlassUtil.seg()`，全 App 材质语言彻底统一。

## 二、清理冗余代码

- 删除 `DynFeedView.roundBg()`（已无任何调用）；
- 删除 `SearchActivity` 里创建后从未使用的 `flow` 局部变量；
- 删除 `DynFeedView.glassSeg()` 本地实现，统一收敛到 `GlassUtil.seg()`。

## 三、流畅度与视频加载速度

- **预取线程池化**：播放地址预取从每次 `new Thread()`（含双括号匿名子类）改为固定 2 线程池复用，减少快速连滑时频繁创建/销毁线程的开销，起播取址更快。
- **图片缓存 24MB→32MB**：首页 / 关注 / 搜索列表来回滑动时封面命中率更高，更少走网络。
- **卡片构建零分配优化**：圆形头像轮廓 `ViewOutlineProvider`、V 认证徽章背景提取为全类共享，滑动时不再为每张卡片重复创建。
