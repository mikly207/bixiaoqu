# 哔小趣 v4.64.0 更新说明

> 基于 v4.63.0
> 主题：**去掉跟随手指的透镜球 + 整体调度与视频加载优化**
> 版本：versionCode 166 / versionName 4.64.0

---

## 一、去掉画圈的"光标"（液态透镜球）

截图里画圈的那个**跟随手指出现、带彩色光晕的黑色放大镜圆球**，来自 `LiquidLensLayer` 全屏覆盖层。本版彻底移除：

- 删除 `LiquidLensLayer.java` 源文件（手机/平板两端）
- 删除 MainActivity 中的字段、创建、`addView`、以及触摸回调里的 `setBand / captureBehind / start / move / end` 调用

**保留**底栏选中态的**水珠胶囊滑块**（玻璃 Dock + 跟手滑动高亮 + 点击切页 + Q 弹反馈），视觉其余部分不变。现在按住底栏只会有高亮预览，不再冒出那个彩色圆球。

## 二、整体调度与视频加载速度优化

在现有成熟调度体系（NetPrio / NetQuality / 起播让路 / 分片闸门 / 线路竞速 / playurl 缓存）基础上，做三处低风险增强：

| 优化 | 改动 | 收益 |
|---|---|---|
| 冷启动 DNS 预热并行化 | 7 个域名从单线程串行查询改为 4 线程低优先级池并行 | 移动网络下省去累加的 300~900ms 握手准备，点开第一屏时已预热完 |
| 起播兜底窗口收紧 | `beginStartup` 上限 6000ms → 4500ms | 首帧异常不回调时，预取/弹幕/互动恢复更早，不再干等 6 秒 |
| 连接预热超时收紧 | `warmConnection` 5000ms → 3500ms | 预热失败早失败早放行，不长时间占用后台线程 |
| 版本号一致性 | `BxqApp.VERSION` v4.60.1 → v4.64.0 | 关于页/日志版本读数正确 |

均不影响正式请求的超时与带宽策略，只在后台准备阶段提速。
