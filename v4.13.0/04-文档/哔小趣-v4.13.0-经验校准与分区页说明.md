## 一、经验值校准（对照参考图 21752/28800）

**根因**：旧版经验值读的是 `x/web-interface/card`（别人主页接口），该接口**不返回 `level_info`**，所以取到 0 → 显示「0/—」。

**修复**：
1. 改从登录态 `x/web-interface/nav` 读取真实的 `level_info`（含 `current_level / current_exp / next_exp / current_min`）并覆盖；
2. 显示口径与官方一致：`当前累计经验 / 升级所需累计经验`（如 `21752/28800`）；
3. 进度条按当前等级区间 `(current_exp - current_min) / (next_exp - current_min)` 计算，与官方「约六成」观感一致（旧版是直接 `cur/next`，偏高）；
4. 满级（`next_exp=0`）显示「经验已满」且进度条拉满；未登录显示「登录后可见」。

## 二、首页右上角「…」→ 分区页

**入口**：首页顶部频道栏（推荐/热门/动画/影视/新番）最右侧的「•••」，点击打开分区页（参照 B 站客户端）。

**分区页内容**（新建 `ZoneActivity`，纯 Java 动态建 UI，兼容 minSdk 22）：
- 顶部「分区」标题 + 返回；
- **全部分区**：4 列彩色图标网格，共 28 个分区（番剧、国创、纪录片、电影、电视剧、综艺、影视、娱乐、音乐、舞蹈、动画、绘画、鬼畜、游戏、资讯、知识、人工智能、科技数码、汽车、时尚美妆、家装房产、户外潮流、健身、体育运动、手工、美食、小剧场、旅游出行）；
- 点分区 → 拉取该分区 B 站排行榜视频（`ranking/v2?rid=`），封面 + 标题 + UP + 播放量列表；
- 点视频 → 进入播放页；列表页可返回分区网格；
- 配色随时应用主题（深色/浅色）切换。
