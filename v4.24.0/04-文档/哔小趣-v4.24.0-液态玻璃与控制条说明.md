# 哔小趣 v4.24.0 · 液态玻璃重做 + 横屏控制条压到一半

> 本版针对用户反馈的两条：**「塑料感特别严重」** 和 **「横屏播放时拉低高度，低至现在的一半」**。

---

## 一、塑料感到底从哪来（先定位，再动手）

上一版（v4.23.0）虽然做了液态玻璃，但仍然像塑料。复盘后确认有三个具体来源，**每一个都是"实色块"**：

| # | 位置 | 旧写法 | 为什么像塑料 |
|---|---|---|---|
| 1 | 玻璃板底盘 | `LinearGradient(0x1A1C24 α=163 → 0x0A0C11 α=190)` | **64%~75% 不透明的深灰蓝实色**，压下去就是一块实色塑料板 |
| 2 | 胶囊按钮 | `GradientDrawable(0x992A2F3A → 0x8C1D2129)` + 1px 白描边 | **60% 不透明深灰实色 + 描边** = 塑料按钮三要素齐全 |
| 3 | 圆形按钮 | `Ic.glass()` 纯色底 + `0x26FFFFFF` 描边 | 同上 |

更糟的是 **2 号和 1 号互相叠加**：深灰按钮压在深灰板上，两层实色糊在一起，中间没有任何"光学"，整条控制条就是一块贴在画面上的深灰胶皮。

> 塑料感的本质不是"颜色不好看"，而是 **玻璃本该有的三样东西一样都没有**：透、化、折。

## 二、v4.24.0 的做法：把"颜色"换成"光学"

真玻璃之所以是玻璃，不是因为它是灰的，而是因为它会做三件事：

| 光学现象 | 本版怎么做 | 代码位置 |
|---|---|---|
| **透** | 底盘压暗从 **75% 降到 27%**，身体几乎不留颜色，底下的视频画面要能看见 | `GlassPanel.tint()` / `shFill` |
| **化** | 磨砂 = **乳白雾层 + 双层颗粒**（细颗粒 64px + 粗颗粒 22px 交叉，不规则才像磨砂） | `shHaze` / `ensureNoise()` |
| **折** | 边缘一圈 **折射双线**：外侧 1dp 暗线（厚度）+ 内侧 1dp 亮线（受光）+ 顶棱一道更亮的细线 | `shEdge` / `shSpec` |
| **悬浮** | 底缘一条"地面反射"亮线，把玻璃托起来 | `shFootL` |

### 新增 `GlassChip`（薄玻璃片）

专门给按钮/圆钮用。它只画三样东西，**主体颜色保持完全透明**：

```
① 磨砂雾   0x28FFFFFF → 0x14FFFFFF   （乳白雾）
② 边缘折射 内缩 1dp 亮线 0x8E → 0x1C，底缘聚暗 0x34
③ 顶棱高光 0xC6FFFFFF，3.5dp 内衰减
④ 底缘反光 中间亮两头淡的一条线
```

于是按钮不再是一块"深灰圆角矩形"，而是**浮在玻璃板上的薄玻璃片**，底下的画面透得上来。

### 配套调整

- **文字自带投影**（`glassText()`）：玻璃底盘半透明，白字压在亮画面上会糊，给每个字套一圈 2dp 暗边，亮背景暗背景都读得清。
- **按下反馈**：不是变实色，是整片玻璃"吸一口光"（提亮 0x1C）。
- **外投影**：从 3 层小偏移硬阴影改成 4 层大范围柔影（旧版像贴纸，新版是"离画面很近地浮着"）。
- **扫光**：从"整块擦白"改成沿顶棱跑过的一道细亮光。

## 三、横屏控制条：132dp → 58dp（44%）

| | v4.23.0 | v4.24.0 |
|---|---|---|
| 结构 | 三行满宽深灰板 | **单行玻璃胶囊（居中） + 独立满宽进度线** |
| 高度 | 132dp | **58dp** |
| 横向 | 压满整屏的实色板 | 宽度自适应内容、居中，两侧画面完整露出 |
| 播放键 | 40dp 圆钮 | 28dp 玻璃圆钮 |
| 进度条 | 板内 3dp/13dp 圆点、高 32dp | **独立成线**，2dp 轨道 + 10dp 圆点、高 16dp，满宽 |
| 胶囊 | 高 34dp | 高 26dp |

功能一个没少：播放/暂停、时间、弹幕开关、发弹幕、选集、下一集、倍速、画质、更多、全屏。

### 配套的结构性修复

1. **控制条容器化**：新增 `ctrlWrap`，把「玻璃板 + 进度线」绑成一个整体。
   以前只搬 `ctrlBar`，切分屏/全屏时进度线会留在原地跟按钮对不上；现在整块一起搬（`ctrlToOverlay` / `ctrlToRootFlow`）。
2. **显隐统一入口** `setCtrlVisible()`：以前有 5 处直接 `ctrlBar.setVisibility()`，进度线不同步；现在全部走统一入口。
3. **窄屏自适应** `fitCtrlRow()`：控制条是一行，手机横屏只有 ~640dp 宽，放不下右边的按钮会被直接裁掉。按可用宽度逐级减员：

   | 可用宽度 | 发弹幕 | 下一集 | 画质 |
   |---|---|---|---|
   | ≥ 615dp | ✅ | ✅ | ✅ |
   | ≥ 557dp | ✅ | ❌ | ✅ |
   | ≥ 506dp | ❌ | ✅ | ✅ |
   | ≥ 448dp | ❌ | ❌ | ✅ |
   | < 448dp | ❌ | ❌ | ❌ |

   **核心功能（播放、时间、进度线、弹幕开关、选集、倍速、全屏）永远保留。**
