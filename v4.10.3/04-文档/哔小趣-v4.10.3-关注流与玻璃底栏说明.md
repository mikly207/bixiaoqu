# 哔小趣 v4.10.3 · 关注动态流重做 + 玻璃胶囊底栏

- 版本：**4.10.3**（versionCode 62）
- 安装包：`哔小趣-v4.10.3.apk`（619 KB）
- 签名不变，可直接覆盖安装

---

## 一、「动态」页改成关注流（参考图一）

底栏第二格原来只是一张"关注的人列表"（头像 + 签名），现在换成完整的 B 站「关注」页结构：

```
关注（标题）                              刷新
┌──────────┬──────────┐
│   全部    │   视频    │   ← 分段，选中粉色加粗
└──────────┴──────────┘
最常访问
◉  ◉  ◉  ◉  ◉              ← 横滑圆形头像，右下角小粉点
────────────────────────
[头像] 音乐人张筱迪 🟡V            ⋮
       41分钟前 · 投稿了视频
┌────────────────────────┐
│        视频封面           │
│ 02:34  1344播放 1弹幕  🔇 │
└────────────────────────┘
凌晨5点来灵感，怒写一首英雄小曲
  转发        评论 12        点赞 57
────────────────────────
```

**数据**：新增 `BiliApi.followDynamic(type, offset)`，走 `x/polymer/web-dynamic/v1/feed/all`，`type=all/video`，带 offset 分页。需要登录。

**新类** `DynFeedView`：

- 顶部标题栏（刷新）、全部/视频分段（切换后清空重拉）
- 最常访问：取关注列表前 10 个，48dp 圆头像 + 名字 + 右下角在线小点，可点进 UP 空间
- 动态卡：38dp 头像、粉色昵称 + 黄 V、`时间 · 投稿了视频`、右上三点（打开 UP 空间 / 复制链接）
- 视频卡：16:9、8dp 圆角、底部渐变条显示 `时长 / 播放 / 弹幕`
- 标题 15.5sp 加粗两行
- 操作行：转发 / 评论 / 点赞三等分，**点赞真会调 `x/web-interface/archive/like`**，本地即时变色 + 计数
- 图片动态（`major.draw`）也能显示首图
- 底部「加载更多」，没有更多时变灰

进入动态页时会把全局搜索栏收起，用页面自带的「关注」标题，避免顶部两层栏叠着。

## 二、底栏改成参考图二的样式

结构从三格（首页/动态/我的）改成 **五格**：

```
[首页]  [动态]  [ ＋ ]  [消息]  [我的]
                  ↑ 主题粉圆角胶囊
```

- **选中态**：单元格里套一层 50dp 高、22dp 圆角的浅灰胶囊（深色 `#343841` / 浅色 `#E9ECF2`），图标与文字同时变主题粉
- **加号**：58×38 圆角胶囊，主题粉底 + 白色加号，点开快捷入口（游戏厅 / 留声机 / 离线缓存 / 搜索）
- **玻璃光影**（`LiquidNavBar` 七层叠加，未改动材质，只换了内部结构）：
  1. 外投影三层递减
  2. 主体自上而下深色渐变
  3. 顶部 62% 白色受光面
  4. 上沿 1.5dp 高亮棱线
  5. 左右各 16% 端头侧光
  6. 1.2dp 上亮下暗外描边
  7. 内侧底边暗影
- 尺寸：左右 14dp、底部 18dp、高 62dp，圆角半径 = 高度一半，保持长椭圆
- 内容区底部留白同步调到 96dp，最后一行不会被压住

## 三、行为细节

- 手指在底栏上滑动时，经过哪格哪格亮（胶囊跟着走），松手才真正切页；滑过加号不改变当前高亮
- 「消息」格点开私信列表，返回后回到首页
- 动态页实例会复用，来回切 tab 不会重复拉数据；切主题重建时自动重拉
