## 四、修复：神庙逃亡上滑不能跳跃

**根因**：跳跃物理的符号写反了。
旧代码 `jumpV = -1120f`（负值）配合 `jumpY += jumpV * s`，
使得离地高度在**第一帧就变成负数**，随即被 `if (jumpY <= 0)` 判定为已落地，
于是**角色永远跳不起来**——上滑手势被正确识别了，但物理量立刻被清零。

**修复**：
- 向上速度取正（`jumpV = 1180f`），重力向下为负（`jumpV -= 3000f * s`）
- 落地条件改为 `jumpY <= 0 && jumpV <= 0`（必须"已落地且仍在下落"才归零）
- 落地阴影随跳跃高度缩放，腾空感更明显

## 五、留声机：在线视频转 MP3

新增「**在线转MP3**」按钮（顶部栏，在「视频转MP3」旁边）。

**与上一版的区别**：
- 上一版「视频转MP3」选的是**手机里的本地视频文件**
- 本版「在线转MP3」选的是**本软件内正在推荐的在线视频**（B 站），直接从网络取音轨

流程：
1. 拉取软件内的在线视频列表（首页推荐流 + 热门榜兜底）
2. 点某个视频 → 解析播放信息 → 选取码率最高的音轨
3. **带 Referer 下载音轨**（B 站直链必须带 Referer，否则 403）
4. 提取音轨 → LAME 编码为 192kbps MP3
5. 存入留声机曲库 → **自动加入列表并直接播放**

转换完成的歌曲带原标题与 UP 主名，会出现在曲库最前面并立即播放。
