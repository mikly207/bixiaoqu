# 哔小趣 v4.14.4 — 悬空液态玻璃底栏

## 需求
底部导航栏悬空、做成苹果风格液态玻璃，要求通透、有质感。

## 为什么之前不通透
旧版深色模式下底栏是**实心不透明**填充 `0xFF16181D`——不管加多少高光，背后内容都一点透不出来，所以看起来是一块"死板的黑条"，而不是玻璃。

## 这次的实现（真·液态玻璃，四个要素）
| 要素 | 做法 |
|---|---|
| **通透** | 抓取底栏背后 `content` 的真实画面 → 缩小到 480px → 本地高斯模糊（纯 Java 分离式 box blur，实测 12ms）→ 作为半透明背景填充。背后封面、文字会隐约透上来。 |
| **材质** | 在模糊层上叠一层渐变半透明染色（深色 `0x5C→0x8A`，浅色 `0x9C→0xD6`），既透光又压住杂乱、保证图标文字清晰。选中胶囊也改为半透明，不再糊成实色块。 |
| **边缘** | 整圈"上亮下暗"受光高光描边 + 顶缘一缕青→粉彩色色散 + 顶部棱高光细线 + 左右端侧光——这是玻璃质感最直接的来源。 |
| **悬浮** | 三层递减柔和投影；离底间距从 10dp 加大到 18dp，左右 14→16dp，悬空更明显。 |

## 性能与兼容
- 模糊背景**低频刷新**：首屏布局完成、切换板块、回到前台各抓一次，不做每帧刷新，不抢播放带宽与算力。
- 纯 `Canvas/Paint/Bitmap` 基础 API + 自实现 box blur，不依赖 RenderScript / RenderEffect，API22（Android 5.1）到 Android 17 全可用。
- 抓取放在 `try/catch` 内，失败时保留上一次模糊背景或退回实色，绝不影响底栏交互。
- 保留原有的按住透镜放大、滑动预览、点击 Q 弹反馈。
