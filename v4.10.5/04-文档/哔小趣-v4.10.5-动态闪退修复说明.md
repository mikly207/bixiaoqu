# v4.10.5 · 修复「点动态闪退」

## 一、你截图里的关键信息

截图右侧的应用信息显示 **已安装 4.10.3 (62)**，所以崩溃发生在 v4.10.3 的动态页上，
和刚发的 v4.10.4（只改了底栏）不是同一处问题。

从截图还能看出：页面已经画出来了（「关注」标题、全部/视频、最常访问都在），
卡在 **「加载中…」** 然后退出。
说明构建没问题，是**第一屏卡片渲染那一刻崩的**。

## 二、崩溃原因

v4.10.3 的动态页用的是：

```
ListView + addHeaderView(标题) + addHeaderView(空状态) + addFooterView(加载更多) + Adapter
```

这套组合是 Android 里最容易出事的结构：

- 三个 header/footer 的 position 偏移与 adapter 的 `getCount` 一旦不同步，
  列表在测量时就会抛 `IndexOutOfBoundsException` / `IllegalStateException`；
- `getView` 里复用 `DynCard`，卡片内部持有 5 个 ImageView、4 个 TextView，
  任何一条数据缺字段（比如转发动态没有 `archive`）都会让复用实例的可见性错乱；
- header 里「最常访问」是动态增删子 View 的，列表高度变化与 adapter 通知时序一冲突就崩。

这些在模拟器/部分机型上不会必现，但在「数据回来的瞬间」刚好撞上就会闪退。

## 三、这一版怎么改的

**把 ListView 整套拆掉，改成 ScrollView + LinearLayout 逐条填充。**

| 旧 | 新 |
| --- | --- |
| ListView + Adapter + 3 个 header/footer | ScrollView + 一个 LinearLayout |
| 卡片复用（convertView） | 每条独立构建，不复用 |
| position 偏移、getCount 同步 | 不存在这些概念 |
| 出错整页崩 | 单条出错只跳过这一条 |

一页十几条动态，逐条建视图的开销可以忽略；换来的是没有 Adapter 就没有那一整类崩溃。

### 另外加了三层护栏

1. `switchTab(1)` 整段包 `try-catch`：即使还有别的意外，也只会在页面里显示
   「动态页打开失败 + 异常名」，**不会再闪退**。
2. 每一张卡片单独 `try-catch`：某条数据异常只跳过这一条，其它照常显示。
3. 所有网络回调先判 `isAttachedToWindow()`：页面已经切走就不再碰 UI。

非致命异常会写进 `Android/data/com.bixiaoqu.app/files/boot.txt`，前缀 `dyn/`。
