# 哔小趣 v4.71.0 液态玻璃与旋转排版修复版

## 本次修复三个问题

### ① 修复透明度过低（横屏底栏几乎看不见）
v4.69.0 把横屏底栏整条黑色底板全部删掉后，底栏过于透明、三个 tab 在亮色封面上几乎看不清。本版在横屏透明模式下**恢复液态玻璃底板**：

- 重新绘制磨砂玻璃底（模糊后的背后封面 + 淡染色），但比竖屏更通透
- 保留顶部受光、左右侧光、边缘细描边 —— 通透但有玻璃质感
- 不做沉重三层投影与底部暗边，避免黑色底板回归
- 半透明水珠选中胶囊保留，三个 tab 在亮/暗封面上都清晰可读

竖屏完全不变，仍是原来的液态玻璃底栏。

### ② 加上液态玻璃质感
`LiquidNavBar` 透明模式现在包含完整玻璃材质分层：磨砂模糊底（alpha 0xDE）→ 淡染色 → 顶部受光 → 两侧受光 → 边缘描边 → 水珠高光。既通透又能看清内容，质感接近 Apple Music 液态玻璃。

### ③ 修复横屏变竖屏时排列排版错位
**根因**：横屏切竖屏重建列表时，卡片宽度用 `getDisplayMetrics().widthPixels`，该值在旋转回调后可能滞后，仍按横屏宽度计算，导致竖屏卡片过窄、排列挤压错位；同时旋转重排顺序是"先重建列表、后还原布局参数"，竖屏会短暂沿用横屏的 4dp 底部 padding。

**修复**：
- `FeedAdapter` 新增带实测宽度的构造函数，卡片宽度优先用**视图实测宽度**（`content.getWidth()`），旋转后一定是新方向的真实宽度，从根上消除错位。
- 旋转重排顺序调整为**先还原布局参数（底栏/顶栏/频道栏/内容区 padding），再重建列表**，竖屏底部留白正确恢复为 74dp。
- 旋转仍不重建 Activity、不重新请求数据，图片走内存缓存秒显。
