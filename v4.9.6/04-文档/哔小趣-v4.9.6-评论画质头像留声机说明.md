## 一、评论区不再糊满屏幕

### 旧做法的问题

点「评论」→ `startActivity(CommentActivity)` → 整页被评论占满，视频完全看不见。
想对照画面看评论，只能退出去再进来，播放进度还断了。

### 现在的做法：底部抽屉

新增 `CommentSheet.java`（约 470 行），是叠在播放页上的一个**可收起抽屉**：

| 特性 | 说明 |
| --- | --- |
| 高度 | 约 62% 屏高（横屏按屏高封顶），**上方三分之一画面始终可见** |
| 视频 | 不暂停、不销毁，抽屉开着也在播 |
| 顶部 | 20dp 圆角 + 拖拽把手，下滑超过 28% 高度（或快速下甩）即收起 |
| 标题行 | 「评论 N」+「按热度」+ 右上角 × |
| 列表 | 头像 / 昵称 / 正文 / 时间 / 点赞数，与网页版一致 |
| 底部 | 「发个友善的评论…」输入框 + 发送，发完自动刷新 |
| 触摸 | 面板 `setClickable(true)` 吃掉事件，**不会穿透**到下面的视频手势（否则点评论会误触暂停或翻页） |

另外两处联动：
- 翻页 / 点推荐换视频时，抽屉自动收起（否则里面还是上一条的评论）；
- 同一个视频重复打开不重复拉取，避免列表闪一下。

`CommentActivity` 保留未删，但播放页已不再跳转它。

## 二、画质设置：从「黑话」变成「人话」

### 旧版

一个干名单：`自动（最高可用） / 4K 超清 / 2K 超清 / 1080P60 / 1080P / 720P / 480P / 360P`，
普通用户既不知道 1080P60 的 60 是什么意思，也不知道自己手机能不能播 4K。

### 新版面板

每一档都是一行标题 + 一句解释，直接回答「清不清楚、费不费流量、适合谁」：

| 档位 | 面板里的解释 |
| --- | --- |
| 自动（推荐） | 按网络和手机自动挑，不用操心 |
| 超清 4K | 最清晰，需要手机和网络都跟得上，流量也最费 |
| 超清 2K | 比 1080P 更细腻，网络好的时候选它 |
| 高帧率 1080P（60 帧） | 60 帧更顺滑，适合游戏、运动、舞蹈类 |
| 高清 1080P | 清晰和流量的平衡点，大多数手机够用 |
| 标清 720P | 省流量，小屏上看几乎没差别 |
| 流畅 480P | 网速一般时也能播，细节会糊一点 |
| 极速 360P | 只求能播完时选它，最省流量 |

面板顶部还会直接告诉你：

> 这台手机最高能播 **4K**，选更高的档位会自动用最高可播的那一档。

超出本机解码上限的档位右侧标「超出本机上限」，当前档位标「使用中 ✓」。

### 「解码」按钮也改了

- 按钮文案：`4K · H.264可解` → **`最高可播 4K`**（一句话结论，不再摆编码术语）
- 点开是白话说明：
  - 这台手机最高能播什么
  - 本视频提供了哪些画质，✓ / ✗ 各代表能不能播
  - 编码名后面加了人话注解：`H.264（兼容最好）`、`H.265（更省流量）`、`AV1（最新，部分手机不支持）`
  - 最后一句兜底提示：播不出来就降一档
- 底部按钮上的 `1080P60` 改为 `1080P·60帧`

## 三、消息页 UP 主头像不显示

### 根因

消息页的昵称和头像走的是批量名片接口：

```
https://api.vc.bilibili.com/account/v1/user/cards?uids=...
```

这个 IM 域接口**对第三方客户端风控很严**，一旦返回 `code != 0` 或 `data` 为空，
代码里是静默 catch，结果就是：50 个会话全是灰头像、名字全变成「用户 1260095253」——
和你截图的状况完全一致。

### 修复

1. 新增 `BiliApi.card(mid)`，用公开的 `x/web-interface/card?mid=` 单查（不需要 WBI、不需要登录）；
2. 消息页改成两级策略：
   - 先把会话列表**立即上屏**（不让人干等）；
   - 再后台逐个回补缺头像的会话（最多 24 个），补到就刷新列表。
3. 昵称也会一并从「用户 xxx」替换成真实昵称。

## 四、底栏「消息」→「留声机」

### 底栏

- 文案：`消息` → **`留声机`**
- 图标：新画了 `res/drawable/ic_g_record.xml`（黑胶唱片 + 唱臂矢量图）
- 点它进入独立的 `MusicActivity`，**不占内容区、不改变当前高亮**（回来还是原来那一页）
- 原来的消息入口没有丢：仍在「我的 → 消息」

### 留声机能做什么

**1. 本地音乐（完全离线）**

- 用 `MediaStore.Audio` 扫描本机音乐（过滤掉 30 秒以下的提示音），最多 2000 首
- 列表显示序号 / 歌名 / 歌手 / 时长，点一首就播
- 播放器：黑胶唱片 + 专辑封面 + 唱针中心轴 + 唱片旋转动画（播放转、暂停停）
- 进度条可拖动，实时时间 `mm:ss / mm:ss`
- 上一首 / 播放暂停 / 下一首，播完自动下一首
- `MediaPlayer` + `AudioAttributes(USAGE_MEDIA)`，走系统媒体音量

**2. 一键去 QQ 音乐**

右上角 `QQ音乐` 按钮：优先用包名拉起 QQ 音乐 App，失败则尝试 `qqmusic://`，
再失败打开 `https://y.qq.com/`。

> **为什么不是「接入曲库」**：QQ 音乐没有对第三方开放的音乐接口，
> 曲库受版权保护，绕过登录和加密签名去抓取属于违规。
> 所以这里做的是「把你送到 QQ 音乐去听」，而不是把它的曲库搬进来。

### 权限

- Android 13+：`READ_MEDIA_AUDIO`
- Android 12 及以下：`READ_EXTERNAL_STORAGE`（maxSdkVersion=32）
- 拒绝授权时会弹窗说明，并提示去系统设置里手动打开
- Android 11+ 包可见性：Manifest 里加了 `<queries><package android:name="com.tencent.qqmusic"/></queries>`
