# 哔小趣 v4.14.0 —— 录音棚 + 小说吧

本次新增两大功能，均为独立模块，不影响原有播放内核与网络链路。

## 一、留声机 → 录音棚

从「我的 → 留声机」页右上角新增「录音棚」入口。

| 功能 | 说明 |
|---|---|
| 录音 | 麦克风录音，MPEG-4/AAC 16k 单声道，保存到应用私有目录，无需存储权限 |
| 播放 | 点录音条目直接播放，再点暂停 |
| 长按菜单 | 播放 / 转文字 / 重命名 / 删除 |
| 权限 | 首次录音运行时申请麦克风权限（API<23 安装即授予） |

### 在线转文字
- 用户选择的是「在线识别接口」，采用**百度语音开放平台**的标准 REST API。
- 首次使用点右上角「转文字设置」，填入你自己的 **API Key / Secret Key**（到 ai.baidu.com 免费创建应用即可获得，有免费额度）。
- 密钥仅存本机；App **不内置任何第三方凭证、不破解任何服务**。无密钥时不发起任何请求。
- 识别结果可编辑、复制到剪贴板、保存为同名 `.txt`。
- 说明：识别准确率依赖百度服务与录音质量；静音/噪声大可能识别为空。

## 二、小说吧（留声机下方新栏目）

「我的」页留声机卡片下方新增「小说吧」，四个 tab：**书架 / 搜索 / 书源 / 护眼**。

### 书源聚合阅读
- 采用**书源规则框架**：书源是一段 JSON，定义搜索/目录/正文的正则提取规则。
- 点「书源 → +添加书源」粘贴 JSON；「规则说明」里有全部字段解释，默认附带一个 `example.com` 的格式模板。
- 搜索会依次访问你添加的书源，聚合结果；点结果即加入书架并进入目录 → 正文。
- 书架记录阅读进度（第几章），长按可移出书架。
- 正文自动去 HTML 标签、分段缩进，支持上一章/下一章/回目录。

### 合规边界（重要）
- App **不内置任何小说内容或盗版书源**，书源完全由用户自行添加；来源合法性由用户自行负责。
- 应用只提供通用的「按规则抓公开网页 → 正则提取 → 文本渲染」能力，不做任何破解、绕过登录或版权规避。
- 请仅添加你有权访问的公开来源。

### 护眼模式
- 「护眼」tab 提供 4 种背景：**普通（跟随主题）/ 米黄 / 豆沙绿 / 夜间**。
- 正文字号 16~30sp 可调，自动保存；设置立即生效。
