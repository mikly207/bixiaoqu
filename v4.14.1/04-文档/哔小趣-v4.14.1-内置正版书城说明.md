# 哔小趣 v4.14.1 —— 小说吧内置正版书城

## 本次改动

小说吧打开即进入全新的「**书城**」tab，内置一批正版小说平台网址，点按即可在 App 内阅读，无需自己添加书源。

### 1. 内置书城（默认首页）
小说吧 tab 栏新增第一位「书城」，内置 10 个正版小说平台网址入口：

| 平台 | 网址 |
|---|---|
| 起点中文网 | https://www.qidian.com/ |
| 番茄免费小说 | https://fanqienovel.com/ |
| 七猫免费小说 | https://www.qimao.com/ |
| 晋江文学城 | https://www.jjwxc.net/ |
| 纵横中文网 | https://www.zongheng.com/ |
| 17K小说网 | https://www.17k.com/ |
| 书旗小说 | https://www.shuqi.com/ |
| QQ阅读 | https://book.qq.com/ |
| 掌阅iReader | https://www.ireader.com/ |
| 小米小说 | https://reader.mi.com/ |

每个入口显示平台名 + 简介 + 网址，点按在 App 内置浏览器打开。

### 2. 内置浏览器（护眼同步）
新建 `NovelWebActivity`：
- WebView 打开网址，支持 JS / DOM Storage，页面内跳转留在 App 内
- 顶栏「护眼」按钮循环切换：普通 / 米黄 / 豆绿 / 夜间，通过 CSS 注入实时套用到网页，与小说吧护眼设置同步
- 顶栏「刷新」「浏览器」按钮；返回键先退网页历史再退出
- 护眼设置与字号沿用小说吧「护眼」tab 的配置，自动保存

### 3. 保留的能力
原「书架 / 搜索 / 书源 / 护眼」四个 tab 全部保留，索引映射未变：
- 书架：收藏 + 阅读进度
- 搜索：走用户自添加的书源，聚合公开网页索引
- 书源：JSON 规则自定义管理
- 护眼：4 种背景 + 字号调节

## 合规说明
内置的是起点、番茄、七猫等**正版平台的官方网址入口（书签导航）**，不内置任何盗版小说内容，不破解任何网站登录，也不抓取受版权保护的正文。各网站是否免费、是否需要登录，以网站自身为准；用户自添加的书源同样需自行确认来源合法性。

## 使用提示
装上后进入「我的 → 小说吧」，默认就是书城，点任意平台即可进入阅读；网页内如出现登录/付费提示，属于该网站自身要求，App 不做绕过。想调整护眼配色，在网页顶栏点「护眼」循环切换，或到小说吧「护眼」tab 里设置背景与字号。
