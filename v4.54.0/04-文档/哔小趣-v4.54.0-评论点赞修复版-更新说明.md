# 哔小趣 v4.54.0 · 评论点赞修复版

> 一句话：修复评论区点「赞」提示 **HTTP 404**、点了没反应的问题。点赞现在真正生效，失败也会给出看得懂的提示。

---

## 一、这次修了什么

| 问题 | 原因 | 修复 |
|---|---|---|
| 评论区点赞 / 取消点赞弹「HTTP 404」，点了没用 | B 站下线了旧的点赞接口 `/x/v2/reply/like`，而 App 仍在调用它，服务器直接返回 404 | 改用 B 站现行官方接口 `/x/v2/reply/action`，参数不变（oid=视频aid、type=1、rpid、action、csrf） |
| 点赞失败只弹一串数字或英文 | 原逻辑把底层错误原文直接弹出来 | 常见错误码翻译成人话（未登录、登录过期、操作频繁、评论区关闭、评论不存在） |

- 平板版、手机版 **两个版本都已同步修复**。
- 点赞的交互体验不变：先乐观更新（数字 +1、图标变亮），网络失败再自动回滚。

---

## 二、这次没有改动的地方

- 离线激活码方案、私信一键已读、直播布局 / 全屏 / 画质等均保持 v4.53 现状，未做任何改动。
- 只动了评论点赞这一处接口调用。

## 四、安装说明

1. 直接安装对应机型的 APK（平板装平板版、手机装手机版），版本号更高，可覆盖旧版。
2. 打开任意视频 → 评论区 → 点评论右侧的「赞」，数字应正常 +1、图标变亮；再点一次取消。
3. 若提示「账号未登录 / 登录已过期」，请先登录 B 站账号再点赞。
