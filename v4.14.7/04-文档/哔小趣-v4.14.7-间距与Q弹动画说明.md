# 哔小趣 v4.14.7 — UI 间距优化 · Q 弹动画增强

## 一、UI 间距调整（不再挤在一起）
针对搜索页截图里「最近搜索」和「大家都在搜」挤成一团的问题：
- 提示文字与搜索框之间留白加大（7dp → 12dp）
- 「最近搜索」标题下方留白加大（4dp → 9dp），胶囊横向间距 8 → 11dp
- 「大家都在搜」与上一区块间距明显拉开（标题上留白 12 → 20dp），标题与胶囊间距 6 → 10dp
- 推荐胶囊横向、纵向间距 8 → 11dp，换行测量同步更新，排版更透气

## 二、全 App Q 弹动画增强
新增统一动画工具类 `Bounce.java`，提供「蓄力—弹出—余振」的弹簧动画：
- `pop()`：放大蓄力后带高张力 overshoot 弹回；
- `pressIn()` / `release()`：按下缩小、抬手带回弹，做成按压手感；
- `enterUp()`：从下方带回弹滑入；
- 用 `OvershootInterpolator` + `AnticipateOvershootInterpolator`，API11+ 通用（API22 兼容）。

应用到主要交互点，全部比原来更 Q：
| 位置 | 变化 |
|---|---|
| 底栏图标点击 | 放大峰值 1.32 → 1.42，回弹张力 2.6 → 4.2，更弹 |
| 频道标签切换 | 峰值 1.22 → 1.3，回弹更 Q |
| 板块内容入场 | 位移 4.5% → 6%，回弹插值更明显 |
| 首页头像点击 | 进「我的」前先弹一下（1.22） |
| 搜索按钮 | 点击弹一下（1.14） |
| 搜索推荐 / 历史胶囊 | 按压缩小 + 抬手回弹 |
| 设置页每一行 | 按压缩小 + 抬手回弹 |
