# 哔小趣 v4.15.0 更新说明

版本：4.15.0（versionCode 96）｜证书不变，可直接覆盖安装

## 修复「大家都在搜」底部标签被裁

**根因**：搜索页原本用「顶部固定区（WRAP_CONTENT）+ 结果 ListView（weight=1 / height=0）」的垂直布局。当标签排到第二行、屏幕空间紧张时，ListView 会强行占住自己的最小高度，把顶部的最后一行标签挤出屏幕底部，圆角按钮就只露出上半截。这与标签本身是 TextView 还是圆角 Button、是否用 FlowLayout 无关，是布局结构的问题。

**修复**：重构搜索页结构——
- 把「状态提示 + 最近搜索 + 大家都在搜」整体改为 **ListView 的 HeaderView**（`addHeaderView`），让它们随列表一起滚动。标签再多也能完整显示、自由滚动，永不被固定区域挤到屏幕外裁切。
- 搜索框保留在页面顶部常驻，输入体验不变。
- 同步修正条目点击的 position：减去 `getHeaderViewsCount()`，避免加了 Header 后点击结果错位（跳过一条）。
- Header 设为不可选中，标签胶囊各自响应点击，互不干扰。
