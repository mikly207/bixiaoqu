# 哔小趣 v4.16.1 —— 推荐 50 条 / 动态左栏 / 横屏分屏 / 搜索热搜

版本号 **v4.16.1**（versionCode 115）· 签名与之前完全一致，直接覆盖安装，不用卸载。

## 一、推荐页：20 条 → 50 条，还能一直往下翻

**改动**

| 项 | 之前 | 现在 |
|---|---|---|
| 首批条数 | 26（上限写死） | **50** |
| 混合源 | 推荐流 20 + 热门 20 + 榜 1 次 | 推荐流 30 × 2 批 + 热门 50 + 榜 100 |
| 继续下翻 | 无 | 滚到底自动续 30 条，直到没有新内容 |
| 封面内存缓存 | 32MB | **48MB**（50 张封面滚动不再互相顶掉） |

**接口实测（真实请求，不是估算）**

```
x/web-interface/wbi/index/top/feed/rcmd   ps=20 → 20 条   ps=30 → 30 条   ps=50 → code -400（上限就是 30）
x/web-interface/popular                     ps=50 → 50 条   pn=1~6 每页都满 50
x/web-interface/ranking/v2                 → 100 条
去重后合计 ≈ 190 条候选 → 取 50
```

**续页去重**：已加载的 bvid 记在 `loadedBvids` 里，续页拿到的重复项直接丢弃；
一条新内容都没有时会提示「没有更多了」，不会静默失败。

## 二、动态页：左头像栏 + 右卡片流（参考图一）

- 左侧竖排一栏：**全部动态**（粉色圆形）+ 关注的 UP 主头像（圆形 + 名字）
- 点头像 → **只看这个 UP 主 的动态**，标题栏同步改成该 UP 主昵称；再点一次取消
- 右侧是原来的动态卡片流（文字 / 视频封面 / 图片九宫格 / 点赞评论转发）
- 竖屏侧栏 78dp，横屏 / 平板 96dp
- **删掉了顶部横排的「最常访问」**——功能已经并进左栏，同一份数据不再渲染两遍

## 三、横屏播放：分屏（参考图二）

横屏进入播放页，现在是**左视频 + 右信息栏**：

```
┌──────────────────┬────────────────────────┐
│                  │ 简介 │ 评论 159           │
│                  │ UP主卡片 + 关注          │
│      视频画面     │ 标题                    │
│   （按比例居中）   │ 5.3万播放 · 158评论 …   │
│                  │ 👍691 💰62 ⭐62 ↗38      │
│  ── 控制条 ──     │ 相关推荐（点即切换）      │
└──────────────────┴────────────────────────┘
```

- 画面按视频自身宽高比摆正，**不变形、上下留黑边**（与图二一致）
- 右侧新增「简介 / 评论 N」分段（评论数取真实数据）
- 右栏推荐列表点击可直接切下一个视频
- 点控制条的全屏按钮 → 切成纯画面；再退全屏 → 自动回到分屏
- 启动时设备就是横屏（平板）→ 直接进分屏

## 四、搜索页：右侧 1/3 热搜（参考图三）

- 宽屏（横屏或宽度 ≥600dp）时，右侧出现 **bilibili 热搜** 栏，占结果区约 1/3
- 每条显示榜单序号、关键词、热度值（前 3 名序号用主色）
- **点热搜词直接搜索**；下方「搜索发现」是几个常搜方向
- 接口：`x/web-interface/search/square?limit=20`（实测 code=0，20 条带 heat_score）
- 旋屏 / 分屏改窗口会自动重建页面（宽窄屏布局不同），关键词和结果都保留

## 六、装完怎么验

1. 覆盖安装 → 首页应有 **50 条**推荐；滑到底会继续加载
2. `我的 → 关注`（或底部「动态」）→ 左侧出现 UP 主头像列，点头像只看该 UP 主
3. 播放页横过来 → 左边视频、右边简介 + 相关推荐
4. 搜索页横过来（或平板）→ 右侧出现热搜栏，点词直接搜
