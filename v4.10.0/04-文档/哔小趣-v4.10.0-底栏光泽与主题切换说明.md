# 哔小趣 v4.10.0 — 底栏回退加强光泽 · 深/浅色切换 · 我的页重做

## 一、底栏：回到上一版，光泽加满

上一版（v4.9.9）把底栏改成「抓背景 + 模糊」，实际在深色界面上反而更暗、更脏，这版全部撤掉，回到 v4.9.8 的实心胶囊路线，尺寸也原样恢复（左右 16dp、底部 26dp、图标 24dp、文字 11.5sp）。

在此之上把光泽堆到七层：

| 层 | 做法 |
| --- | --- |
| 外投影 | 三层递减投影，悬浮感 |
| 主体 | 自下而上深色渐变 `#F22E3340 → #E616181F`，顶部更亮 |
| 顶光 | 上 62% 整片白色渐隐（26% → 0），模拟受光面 |
| 强高光 | 顶部 9dp 一条 `59% 白 → 0`，玻璃最亮的位置 |
| 侧光 | 左右各 16% 宽度的高光渐变，端头弧面才立得起来 |
| 顶棱 | 1.5dp 高亮线（`7AFFFFFF`），亮泽感主要来自这条 |
| 外沿 | 1.2dp 上亮下暗描边（`8CFFFFFF → 1FFFFFFF`） |

浅色模式下自动切白玻璃：主体 `#FFFFFF → #E9ECF2`，描边改深色弱描边，顶棱变纯白。

## 二、深色 / 浅色模式

设置 → 外观 → **深色模式**（新增一行，右侧显示当前是「深色 / 浅色 / 跟随系统」）。

点进去是独立页面，两项：

- **深色跟随系统** —— 打开后完全交给系统的日夜模式；
- **深色模式** —— 手动指定。拨它会自动关掉「跟随系统」。

切换后整个 App 立刻换肤：首页卡片、我的、留声机、游戏厅、设置、搜索、收藏、消息全部跟着变，**视频播放页保持黑底**（避免影响观片）。

实现要点：

- 原来 `C_BG / C_CARD / C_FG / C_SUB` 是 `static final` 常量，切主题也不会变；现在改为可变静态字段 + `applyTheme()`，每个 Activity 在 `onCreate` 里先算一次。
- 主题指纹变了，`onResume` 自动 `recreate()`，并且**记住你原来停在哪一页**，不会切完主题被打回首页。

配色对照：

| | 深色 | 浅色 |
| --- | --- | --- |
| 页面底色 | `#16181D` | `#F3F4F6` |
| 卡片 | `#1F2229` | `#FFFFFF` |
| 主文字 | `#E8EAF0` | `#18191C` |
| 次文字 | `#9AA0AB` | `#61666D` |

具体变化：

- **头图 + 压线大头像**：头图用本人头像放大铺满并做渐变遮罩（B 站没有公开的头图接口），头像 86dp 圆形，负 43dp 上移压在头图下沿，带一圈背景色描边。
- **三栏数据**：粉丝 / 关注 / 获赞，数据来自 `web-interface/card`（获赞对应 `like_num`）。点粉丝、关注进列表，点获赞给一句说明（没有公开列表）。
- **昵称 + 徽章**：昵称右侧挂「年度大会员」（是大会员才显示），下面「粉丝团」「成就勋章」描边胶囊。
- **等级进度条**：LV 标签 + 进度条 + `当前经验/下一级经验`，按 `level_info` 实时计算。
- **签名 + 详情**：签名取 `card.sign`；点「详情」弹窗显示 UID、B 币、签名。
- **编辑资料**：B 站没开放资料编辑接口，直接跳网页版个人空间。
- **分区 tab**：主页 / 动态 / 投稿 / 收藏，动态和收藏都能真跳。
- **投稿网格**：两列，最多显示 6 个，缩略图带播放量、弹幕数、时长，点开直接播。
- 原来那排功能入口（离线缓存 / 历史 / 收藏 / 稍后再看 / 消息）和设置、游戏厅、留声机、退出登录全部保留在下方。

右上角「更多」收了设置、消息、崩溃日志、刷新资料。
