## 一、头像被切半截 —— 已修

**根因**：上一版头像用的是 `topMargin = -44dp` 压线。负 margin 会让父 `LinearLayout` 测量高度时把这段"负高度"算进去，profile 行的实际高度被压成 88-44=44dp，于是：

1. 头像向下溢出了 profile 的边界；
2. 紧跟在后面的「粉丝/关注/获赞」数据卡位置随之上移；
3. 数据卡有不透明底色，直接把头像下半截盖住了。

**改法**：头图与头像行放进同一个 `FrameLayout`（`head`，`clipChildren=false`）：

- 头图仍是 158dp，作为 `head` 的第一个子 View；
- 头像行改成 `head` 的第二个子 View，`topMargin = 114dp`（= 158 − 44，正好压线一半）；
- 头像行 `minimumHeight = 88dp`，保证头像 88dp 完整落在容器内，不再有任何负 margin；
- `head` 用 `WRAP_CONTENT`，实测高度 = 114 + 88 = 202dp，头像底边 202dp，数据卡从 216dp 开始，中间留 14dp。

压线效果和以前一样，但头像是一个完整的圆，不再被裁、不再被卡片压住。

## 二、常用功能上移

页面顺序从「个人信息 → tab → 投稿 → 功能」改成：

```
顶栏 → 头图+头像 → 数据卡 → 等级 → 签名/编辑资料 → UID
     → 常用功能（五宫格）→ 设置/游戏厅/留声机（三行卡）
     → 主页/动态/投稿/收藏 tab → 投稿网格 → 缓存统计 → 登录/退出 → 崩溃日志
```

五宫格与三行卡整体挪到 tab 之前，打开「我的」滚一屏就能看到全部功能入口，不用滑到最底下。

## 三、主页 / 动态 / 投稿 封面不显示 —— 已修

**根因**：`space/arc/search`（投稿）与动态接口返回的封面地址是**明文 HTTP**：

```
http://i0.hdslb.com/bfs/archive/xxxx.jpg
```

而应用 `targetSdk = 34`，`network-security-config` 只对 `127.0.0.1 / localhost` 放行了明文，外部 HTTP 一律被系统拦掉 → `HttpURLConnection` 直接抛异常 → 加载器返回 null，只剩灰色占位块。首页推荐走的是新接口，返回的是 `https://`，所以首页封面一直正常。

**改法**：在 `ImgLoader` 里加统一的协议升级，**一处修复所有页面**：

```java
public static String https(String url) {
    if (url == null) return "";
    String u = url.trim();
    if (u.isEmpty()) return "";
    if (u.startsWith("//"))     return "https:" + u;          // 协议相对地址
    if (u.startsWith("http://")) return "https://" + u.substring(7);
    return u;
}
```

`load()` 与 `prefetch()` 入口都先过一遍，内存/磁盘缓存的 key 也用升级后的地址，命中率不受影响。B 站图床 `i0/i1/i2.hdslb.com` 全部支持 HTTPS，所以转协议后能正常取图。

覆盖到的页面：我的投稿网格、动态页视频封面、动态图片、以及后续任何拿到 `http://` 封面的位置。
