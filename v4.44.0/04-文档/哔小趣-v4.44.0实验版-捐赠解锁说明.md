## 三、登录门禁：捐赠后才能登录

- `promptLoginOrOut()`（唯一登录入口）**前置校验** `Prefs.donated()`：
  - 未捐赠 → 弹出「请先支持我们」引导框，说明最低 1 元捐赠，**不进入登录流程**；
  - 已捐赠 → 才允许走原来的二维码登录 / 验证码登录。
- 捐赠凭证（是否已捐赠 / 金额 / 方式 / 时间）保存在本机 `SharedPreferences`，重启后仍有效。
- 凭证仅本机保存，不涉及账号隐私。

## 四、关于「支付成功」的判定（重要说明）

你提供的是**个人静态收款码**，不是接入微信/支付宝官方支付 SDK 的商户订单。静态码**无法向 App 回传"支付成功"事件**（官方回调需要企业资质 + 服务器 + 支付订单 API）。

因此当前采用个人开发者通用做法：**用户扫码付款成功后，在 App 内点「我已完成支付」经二次确认解锁**。这是基于信任的本地激活，无法自动核对到账。

如果你希望做成**自动验证到账**（付款后无需手动点、系统自动识别），需要：
1. 微信支付 / 支付宝的**商户号与 API 密钥**（企业或个体工商户资质）；
2. 一台服务器接收支付回调并下发给 App；
3. App 端接入对应支付 SDK。

如果具备这些条件，告诉我，我可以接官方支付通道实现自动解锁。
