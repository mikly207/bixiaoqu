# 哔小趣 v4.11.0 更新说明 —— 全安卓版本兼容（Android 5.1 ~ 17）

> versionCode 66 / versionName 4.11.0 · 基于 v4.10.6 · APK 623 KB

## 一、本次目标

最低支持版本从 **Android 10（API 29）降到 Android 5.1（API 22）**，
覆盖 Android 5.1 → 16/17 全部版本；targetSdk 保持 34。
所有 4.9、4.10 的功能与修复（液态玻璃底栏、关注流、楼中楼、弹幕调节面板、我的页排版等）全部保留。

## 二、保证兼容的做法

1. **编译器强制检查**：javac 的 bootclasspath 从 android-34 换成 **android-22** 平台 jar，
   任何超过 API 22 的调用都会直接编译报错——本次共揪出 **28 处**高版本 API，逐个消灭。
2. **新增 `Compat.java` 兼容层**，所有需要高 API 的逻辑收拢到这里，按 `Build.VERSION.SDK_INT` 分流：
   - `hasPerm / requestPerm`：运行时权限统一入口（API<23 权限安装时已授予，直接放行）；
   - `applyRate(MediaPlayer, r)`：倍速走反射调用 `PlaybackParams`（API 23+），API 22 静默跳过；
   - `savePublicLegacy(...)`：API<29 保存到公共 Music/Movies 目录改用 File 直写，无写权限自动回退应用私有目录；
   - `putRelativePath / putPending`：MediaStore 的 `relative_path`、`is_pending` 改为字符串 key 写入，规避 API 29 常量符号；
   - `videoThumb(...)`：本地视频缩略图全版本改走 `MediaMetadataRetriever`，替代 API 29 的 `loadThumbnail`。
3. **逐处修复清单**：
   - 音频工具「保存 MP3」、播放页「保存到相册」：API<29 改公共目录 File 直写；
   - 书架/留声机权限：`checkSelfPermission/requestPermissions`、`READ_MEDIA_VIDEO/AUDIO` 常量全部改为全版本可用实现；
   - 书架缓存查询：`relative_path LIKE ?` 改为全版本都存在的 `DATA LIKE ?` 列；
   - 设置页 Switch 着色：API 24+ 才生效（反射调用），低版本保持系统原生样式；
   - 播放倍速 5 处调用点改走 `Compat.applyRate`；**Android 6.0 以下点倍速会提示「当前系统不支持变速播放」**（系统 MediaPlayer 限制，无法绕过）。
4. **构建链同步调整**：`d8 --min-api 22`（原 29）、aapt2 `--min-sdk-version 22`。

## 三、低版本行为差异（预期内）

| 功能 | Android 5.1~6.0 | Android 7.0+ |
|---|---|---|
| 播放倍速 | 不支持（弹提示） | 完整支持 |
| Switch 粉色着色 | 系统默认样式 | 完整支持 |
| 保存 MP3/MP4 到公共目录 | 需写权限，缺权限时存应用私有目录 | 完整支持 |
| 自适应图标（v26） | 自动回退 PNG 图标 | 完整支持 |
| 明文 HTTP 本地代理 | 系统默认允许 | 由网络安全配置放行 127.0.0.1 |

> 注：Android 5.0（API 21）与 5.1（API 22）平台 jar 的 API 面一致，本包理论上也能在 5.0 安装，
> 但官方支持范围按 **Android 5.1（API 22）** 起算。
