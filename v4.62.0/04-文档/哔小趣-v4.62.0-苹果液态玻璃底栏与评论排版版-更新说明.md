# 哔小趣 v4.62.0 更新说明（苹果液态玻璃底栏与评论排版版）

> 基于 v4.60.1（全屏灰边修复版）。本次只改**底栏样式**与**评论区窗口排版**，其余功能、加密生成器、捐赠/激活码逻辑一律未动。手机端、平板端同步更新。

## 一、底栏改为 Apple Music 风格液态玻璃（开源方案参考）

参考 Convx / AM++（Apple Music 增强模块）/ 飞牛音乐客户端等开源实现的共性设计语言，把原来"给选中格套静态底板"的做法，改为**一颗独立、跟手滑动的液态玻璃水珠**：

| 项 | 旧版 (v4.60.1) | 新版 (v4.62.0) |
|---|---|---|
| 选中态 | 每格各自套一个静态半透明圆角背景 | 一颗水珠胶囊，在底层玻璃之上**平滑滑动**到选中格 |
| 滑动手感 | 切换瞬间跳变 | 手指按住预览时水珠实时跟随，松手带 240ms 缓动到位 |
| 材质 | 单层玻璃胶囊 | 玻璃胶囊 + 水珠双层：半透明染色 + 顶部受光 + 一圈细高光描边 |
| 兼容 | — | 纯 Canvas 绘制（API1 可用），不依赖 RenderScript/RenderEffect，保留原模糊背景抓取与透镜交互 |

实现位置：`LiquidNavBar.java` 新增 `setActiveSlot(float, boolean)` 与 `onDraw` 中的水珠绘制；`MainActivity.java` 的 `styleNav()` 调用它驱动水珠；初始化时无动画直接定位。`LiquidLensLayer` 全屏透镜交互完整保留。

## 二、评论区窗口排版优化（按参考图）

针对参考图里 B 站评论区"层级清晰、留白舒展、楼中楼成块"的观感，做了 6 项调整：

1. **作者行加等级徽章**：用户名后带粉色 `LVn` 等级标识（接口 `member.level` 有值时显示）。
2. **时间 + IP 属地**：形如「8月8日 · 四川」，接口 `ip_location` 有值时展示。
3. **楼中楼卡片化**：二级回复区改为圆角灰底卡片（深色略亮灰 / 浅色浅灰），与主评论明确分层；折叠态也先露出 1~2 条预览回复。
4. **标题层级**：评论数用主题强调色高亮（「评论 **919**」），排序标签改为「按热度 ∨」。
5. **底部输入条**：更圆润的输入框（浅/深主题各自适配）+ 表情按钮，贴近参考图底部工具栏。
6. **行距与分隔**：评论行上下留白加大，条目之间加一条极淡分隔线。

点赞、点踩、回复、楼中楼展开/收起、发送等交互逻辑全部保留，未改动网络接口。
