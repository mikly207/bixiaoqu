# 哔小趣 v4.60.0 沉浸修复版 更新说明

> versionCode 161 · 证书与旧版一致，可直接覆盖安装，数据不丢

## 本次修复：底部小白条沉浸问题

你反馈的「深色界面下底部露出一条系统小白条、播放页退出全屏底部一块白底」——根因是**全工程从未设置系统栏颜色**：Manifest 用的是系统默认 `Theme.DeviceDefault.NoActionBar`，20+ 个页面全是裸 `extends Activity`，状态栏 / 导航栏背景一直沿用系统浅色，深色主题下那条手势区域就突兀地露了出来。

### 修法

新增 `ImmersiveBars` 系统栏沉浸中心，一次性处理四件事：

1. **状态栏 + 导航栏背景跟随页面底色**（`C_BG`）：深色主题深底、浅色主题浅底，不再露白。
2. **关闭手势条强制对比层**（API 29+ `setNavigationBarContrastEnforced(false)`）：这是「就算设了深色导航栏，小白条仍被系统涂成半透明白」的直接原因，最关键的一步。
3. **导航栏分割线透明**（API 28+），消除系统栏与内容之间那条灰线。
4. **图标明暗自适应**：浅色主题下状态栏 / 导航栏图标转深色，避免白底白字看不清。

### 覆盖到每一个页面

- 在 `MainActivity.applyTheme()` 这个所有页面的统一入口接入——iOS 皮肤分支也同步（纯黑主题同样不露白）。
- 播放页 / 阅读页等少数不走 `applyTheme` 的页面，通过 `BxqApp` 全局生命周期回调在 `onActivityResumed` 兜底同步。
- 换肤（`recreate`）、从后台切回前台都会实时重算，颜色永远跟主题一致。

### 全屏进出兼容

播放页、直播页退出全屏时原本用 `SYSTEM_UI_FLAG_VISIBLE`，会把图标明暗重置成白底白字。现在改为恢复本页记录的沉浸态，全屏进出后不再有白条回归 / 图标看不清的问题；全屏播放本身（隐藏系统栏）完全不受影响。

### 兼容性

所有高版本系统 API 均通过反射 / 数值常量调用，在 android-22 的编译环境下可正常构建，运行时按系统版本生效（Android 5.1 ~ 14 全覆盖）。

## 建议实机验证

1. 深色主题下打开首页，看底部手势条区域是否已变深色、融入界面。
2. 打开任意视频全屏再退出，看底部是否仍保持深色、不露白条。
3. 切到浅色主题（含 iOS 纯黑皮肤），看状态栏 / 导航栏图标是否清晰可读。
