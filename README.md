# 哔小趣 (BiliXQ)

一个优质的哔哩哔哩第三方客户端，纯 Java 原生 Android 实现，支持平板与手机双端。

本仓库收录历史发布版本，每个版本目录按统一结构归类。

> 出于安全考虑，签名密钥、私钥、激活码生成器、作者控制台等敏感文件不在本仓库收录；
> 激活码方案时期（v4.49.0–v4.55.0）的源码含私钥，仅分发 APK 与文档。

## 📥 如何下载 APK（重要）

> **在 GitHub 网页/App 里点开 APK 文件会显示 `Sorry about that, but we can't show files that are this big right now.` —— 这不是文件损坏或上传失败，而是 GitHub 不提供二进制大文件的在线预览。APK 本身完好无损，请用下面两种方式下载：**

1. **推荐：从 Releases 下载**（手机端有明确下载按钮，最稳定）
   打开仓库页面的 **Releases** 标签，每个版本都有对应 Release，点 apk 附件即可下载安装。最新版本为 [v4.73.0](../../releases/tag/v4.73.0)。

2. **从版本目录下载**：进入对应版本的 `02-安装包/` 目录，点文件名进入后选择 **Download raw file**（电脑端）；手机端可长按"View raw"用浏览器/下载器打开。

- 手机版用于普通手机，平板版用于平板/大屏设备。
- 所有 APK 同一签名 `CN=Bixiaoqu`，可直接覆盖旧版，激活码、捐赠状态、历史数据不丢失。
