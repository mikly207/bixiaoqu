# 哔小趣 (BiliXQ)

一个优质的哔哩哔哩第三方客户端，纯 Java 原生 Android 实现，支持平板与手机双端。

本次发布：**v4.19.0**

## 本版本内容

| 目录 | 说明 |
|------|------|
| `v4.19.0/01-源码工程/平板版/` | 平板版完整工程（AndroidManifest.xml、build.sh、res/、src/） |
| `v4.19.0/01-源码工程/手机版/` | 手机版完整工程 |
| `v4.19.0/02-安装包/` | 平板版、手机版 APK（可直接安装） |
| `v4.19.0/03-源码压缩包/` | 平板版、手机版源码 zip |
| `v4.19.0/04-文档/` | 更新说明、竖屏样式预览 |

## 构建方式

进入对应工程目录（平板版为 `app`，手机版为 `app_phone` 的源码工程），执行：

```bash
bash build.sh
```

构建产物为当前目录下的 APK，使用仓库内约定的签名配置签名。

## 说明

- 本版本为 v4.19.0 历史发布版，源码与 APK 一一对应。
- 应用仅使用 B 站公开接口，不内置任何账号凭据；登录由官方页面完成，Cookie 仅保存在用户本机。
