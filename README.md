# 哔小趣 (BiliXQ)

一个优质的哔哩哔哩第三方客户端，纯 Java 原生 Android 实现，支持平板与手机双端。

本仓库收录多个历史发布版本，每个版本目录结构一致。

## 每个版本的目录结构

以 `vX.Y.Z/` 为例（v4.52.0 出于安全仅含 `02-安装包/` 与 `04-文档/`）：

| 目录 | 说明 |
|------|------|
| `01-源码工程/平板版/` | 平板版完整工程（AndroidManifest.xml、build.sh、res/、src/） |
| `01-源码工程/手机版/` | 手机版完整工程 |
| `01-源码工程/tools/` | 构建、守卫测试、预览等辅助脚本（部分版本含） |
| `02-安装包/` | 平板版、手机版 APK（可直接安装） |
| `03-源码压缩包/` | 源码 zip |
| `04-文档/` | 更新说明、优化对比图等 |

## 构建方式

进入对应版本工程目录（平板版为 `app`，手机版为 `app_phone` 的源码工程），执行：

```bash
bash build.sh
```

构建产物为当前目录下的 APK，使用仓库内约定的签名配置签名。

## 说明

- 各版本源码与 APK 一一对应，均为历史发布版。
- 应用仅使用 B 站公开接口，不内置任何账号凭据；登录由官方页面完成，Cookie 仅保存在用户本机。
