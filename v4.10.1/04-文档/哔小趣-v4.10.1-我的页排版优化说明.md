# 哔小趣 v4.10.1 · 「我的」页排版优化

- 版本：**4.10.1**（versionCode 60）
- 安装包：`哔小趣-v4.10.1.apk`（606 KB）
- 签名：与之前一致（SHA-256 `0930aba7…b67bb148`），可直接覆盖安装
- 改动范围：只动「我的」页的排版与视觉层次，其它页面、播放器、底栏、游戏厅、留声机逻辑均未改动

---

## 一、这版解决的排版问题

对照旧版截图，逐条处理：

| 旧版问题 | 现在 |
| --- | --- |
| 「编辑资料」做成通栏大按钮，挤在昵称下方，把昵称压成一行小字 | 收成 **28dp 高的小胶囊**，挪到签名行右侧，昵称恢复完整宽度 |
| 粉丝/关注/获赞挤在头像右侧那一小块里，三段数字飘在半空 | 从昵称列里拿出来，做成**整宽三等分数据卡**，中间两条 22dp 竖分隔线 |
| 头图用本人头像放大当背景，画面里出现"一大一小两张同样的脸" | 改为**粉调渐变 + 右上圆形弱水印 + 光晕**，不再重复头像 |
| 等级条右侧的 `0/—` 贴边被切 | 经验文本固定 72dp 宽、右对齐、单行省略，不再溢出 |
| 「设置 / 游戏厅 / 留声机」三张独立卡片各带 10dp 间距，页面碎 | 合并成**一张三行分组卡**，行间 0.7dp 分隔线，左缩进 54dp 对齐文字 |
| 投稿卡没有底色，封面与背景糊在一起 | 卡片底 + 1dp 描边 + 10dp 圆角，封面右下角时长黑胶囊，标题与播放量分层 |
| 页面滚到底，最后几行被悬浮底栏压住 | 内容底部统一留 **98dp** 空白 |

## 二、新的排版结构（自上而下）

1. **头图 158dp**：135° 粉调渐变（深色 `#…` 由 32% 主题粉混背景、浅色 52%），右上 200dp 白色光晕，178dp 圆形头像水印（透明度 16% / 12%），底部渐变融进页面背景
2. **右上角**：两个 34dp 玻璃圆按钮 —— **设置**（新增 `ic_g_set` 线性齿轮图标）+ **更多**
3. **头像行**：88dp 头像压线 −44dp，3dp 背景色描边圆环；右侧昵称 18.5sp 加粗 + 年度大会员标签 + 粉丝团/成就勋章徽章
4. **数据卡**：14dp 边距、14dp 圆角、1dp 描边，三格等分，17sp 加粗数字 + 10.5sp 标签，可点进粉丝/关注列表
5. **等级行**：LV 徽章 + 5dp 细进度条 + 右侧经验值
6. **签名行**：12.5sp 最多三行 + 右侧「编辑资料」胶囊
7. **UID 行**：11sp 次要色小字
8. **分区 tab**：主页 / 动态 / 投稿 / 收藏，等分 46dp 行高，选中粉色加粗 + 20×3dp 下划线
9. **投稿区**：`视频 30+` + `更多 ›`（跳网页版空间），两列卡片网格，最多 6 个，奇数个自动补位不打乱列宽
10. **常用功能**：五宫格（离线缓存 / 历史 / 收藏 / 稍后再看 / 消息），图标统一主题粉
11. **分组卡**：设置 / 游戏厅 / 留声机，每行带一句副标题说明
12. **收尾**：缓存统计 → 登录/退出（46dp 圆角按钮）→ 崩溃日志

## 三、顺手修掉的行为问题

- 「投稿」tab 原来跳的是**收藏夹**，现在改为**滚动到本页投稿区**并高亮该 tab
- 「主页」tab 点击回到页面顶部
- 「更多 ›」原来点了没反应，现在打开 `space.bilibili.com/{uid}/video`
- 头图右上按钮从「搜索」换成「设置」——搜索框在全局顶栏已经有了，避免重复入口

## 四、深浅色

- 全部颜色取自 `C_BG / C_CARD / C_FG / C_SUB / C_ACC`，随主题重建生效
- 卡片在浅色下加 `#E9ECF1` 描边、深色下加 `#2A2F38` 描边，避免白卡贴在浅灰背景上看不出边界
- 浅色头图单独用一套更亮的粉渐变（`#FFD0DE → #FFE8EF → 背景`）
