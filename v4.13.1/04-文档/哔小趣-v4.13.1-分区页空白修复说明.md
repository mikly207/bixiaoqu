# 哔小趣 v4.13.1 更新说明 —— 修复分区页空白

## 问题

v4.13.0 点击首页「…」进入分区页后，只有顶部标题「分区」和返回箭头，下面全空（见反馈截图）。

## 根因

分区页（`ZoneActivity`）里放内容的 `ScrollView` 布局参数写成了：

```java
new LinearLayout.LayoutParams(0, 0, 1f)   // 错误：width=0
```

根布局是**垂直** LinearLayout，`weight=1` 只作用于**高度**，而 width 写死 0 → ScrollView 宽度变成 0px → 里面所有内容被压成零宽，完全不可见。

## 修复

1. **宽度改为 `MATCH_PARENT`**：`new LinearLayout.LayoutParams(MATCH_PARENT, 0, 1f)`，内容正常显示。
2. 顺手按参考图补齐了「**快捷访问**」区：
   - 默认显示「＋ 编辑」，点击进入多选对话框，勾选常用分区；
   - 收藏的分区以小图标横排显示，点击直达对应分区；
   - 选择保存在本地（Prefs），下次进入仍在。
3. 「全部分区」28 个分区的 4 列彩色网格保持。
