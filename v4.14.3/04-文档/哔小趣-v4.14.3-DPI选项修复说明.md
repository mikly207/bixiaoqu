# 哔小趣 v4.14.3 — 界面缩放 / DPI 选项修复

## 问题现象
设置 → 外观 → 「界面缩放 / DPI」点击后，**只弹出一段说明文字 + "取消"按钮**，看不到 100% / 85% / 120% / 自定义 的选项列表，无法进行任何缩放设置。

## 根本原因
Android 5.x（API 22）的 `AlertController` 中，`setMessage()` 与 `setSingleChoiceItems()` **互斥**：

```java
// 出错写法：同时设置了 message 和单选项列表
new AlertDialog.Builder(this)
    .setTitle("界面缩放 / DPI")
    .setMessage("调整整个界面的元素大小……")   // ← 元凶
    .setSingleChoiceItems(items, cur, ...)
```

一旦调用了 `setMessage()`，Dialog 的内容区被文字视图占据，**单选项列表根本不会被挂载**，于是只剩说明文字。同一文件里的「深色模式」「推荐页布局」等对话框只用了 `setSingleChoiceItems`、没有 `setMessage`，所以一直显示正常。

## 修复方案
去掉 `setMessage()`，把关键的"选后自动重启生效"信息并入标题，列表即可正常显示：

```java
// 修复后
new AlertDialog.Builder(this)
    .setTitle("界面缩放 / DPI（选后自动重启生效）")
    .setSingleChoiceItems(items, cur, ...)   // 4 个选项现在正常显示
```

选项文字本身已足够清晰（`标准·100% / 紧凑·85%（手表小屏推荐）/ 宽松·120% / 自定义…50%~200%`），因此说明文字合并进标题无信息损失。
