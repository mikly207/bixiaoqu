## 二、打开顺序：开屏动画 → 直接进入推荐

- 频道默认值从「直播」改为「**推荐**」（`currentChannel = 1`，rid=0）。
- App 启动时**开屏动画照常播放**，动画覆盖层下方的推荐流同时开始加载，
  动画一结束看到的就是推荐视频，**不再默认跳进直播**。
- 直播仍保留为首页频道入口，需要时手动点「直播」进入（体验版，不默认进入）。

## 四、三档画质 + 画面缩放

- **画质**：顶部按钮弹出选择，三档——**标清（qn=64）/ 高清（qn=80，默认）/ 2K（qn=10000）**。
  播放中点选会**复用当前播放器直接重连**，不重建页面。
- **画面缩放**：缩放按钮三档循环——
  - **铺满**：画面裁切铺满屏幕、无黑边；
  - **适应**：完整显示 16:9 画面、上下留黑边；
  - **小窗**：屏宽 62% 的居中悬浮小窗。
  通过容器尺寸 + gravity 实现，零第三方依赖。点按画面仍可呼出播放控制条。

---

## 五、切直播流畅度优化

- 切房间 / 切画质前**先 `stopPlayback()` 停掉旧解码器**，避免两个解码器抢资源导致卡死；
- 起播链路精简为「取流 → 起播」一件事，**不再并发请求主播详情、不再建立弹幕 WebSocket**，
  减少切房间时的网络与线程开销；
- v4.41 的稳定性修复**一行没动**：线程池扩容 + 有界队列、代际隔离（旧连接 410）、
  分片 25s 熔断、有限重连（最多 3 次）、多线路择优 + 亲和 + m3u8 短缓存。退出再进、
  快速连点房间依旧稳定。
