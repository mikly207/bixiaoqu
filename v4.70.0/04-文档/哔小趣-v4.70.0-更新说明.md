# 哔小趣 v4.70.0 流畅度优化版 · 更新说明

## 加载流畅度优化（三项核心）

### 1. Bitmap 内存复用池（inBitmap）—— 解决滑动掉帧主因
- 新增 `reusableBitmaps` 复用池：封面从内存 LRU 淘汰后不直接交给 GC，而是放入复用池（上限 24 块）。
- 解码新封面时优先取池里尺寸匹配（宽高 >= 目标、同为 RGB_565）的 Bitmap 作 `inBitmap` 直接覆盖像素，不再重新分配大块内存。
- 效果：快速滑动列表时 GC 大幅减少，**掉帧/卡顿明显改善**；取不到匹配块时自动回退到正常新建，安全无副作用。

### 2. 滑动中暂停封面预取 —— 解码让位给滚动
- 此前 `onScrollStateChanged` 是空的，fling/拖拽过程中仍持续触发预取解码，抢占解码线程与内存带宽。
- 改为：滑动中（`SCROLL_STATE_FLING` / `TOUCH_SCROLL`）只做轻量续页判断、不预取；停稳（`IDLE`）后一次性补齐即将露出的一批封面。
- 效果：滚动手势更跟手顺滑，停稳后封面照常秒显。

### 3. 主线程回调合并派发 —— 减少消息调度抖动
- 一批封面同时下载完成时，原先为每张图各 post 一个 Runnable 到主线程队列。
- 改为合并成一次 post 遍历派发（回调本身极轻量，仅 setImageBitmap）。
- 效果：停稳瞬间的大批出图不再造成主线程消息队列抖动。
