# 哔小趣 v4.61.0 · 激活码生成器加密版

> 本次只加固「作者侧的激活码生成器」，用户安装的 App（v4.60.1）无需更新，已发出的激活码继续有效。

## 一、修了什么：私钥明文泄密风险

旧版生成器把签名私钥**明文写在文件里**：
- 网页版 HTML 里 `PRIV_PEM = "-----BEGIN PRIVATE KEY-----..."` 直接可见
- 安卓版 APK 里 `PRIV_B64` 明文硬编码
- 源码包里 `donate_priv.pem` 明文备份

任何人拿到这些文件，都能读出私钥、自己伪造任意激活码。本次全部改为**加密存储**。

## 二、加密方案（口令由你自己设置）

- 算法：**PBKDF2-HMAC-SHA256（21 万次迭代）+ AES-256-GCM**，三端（网页 / 安卓 / 备份工具）字节级一致。
- 网页版与安卓版生成器里**只存加密密钥包**，文件内已确认「明文私钥 0 处」。
- 私钥本身没变（还是原来那把），App 内置公钥不动，**已发出的激活码和已装 App 全部照常有效**。

## 三、你的首次使用流程（重要）

1. 打开加密版生成器（网页 HTML 双击，或安装安卓 APK）。
2. 输入**临时初始口令**：`temp-bxq-2026`
   - 这个口令只是首次验证身份，解开后立即作废。
3. 设置**你自己的密码**（至少 8 位，输两遍确认）—— 之后每次打开都用它解锁。
4. 正常填设备 ID、金额，生成激活码。
5. 建议在网页版点「导出加密密钥包」保存一份（换电脑 / 忘记本机数据时用）。

> 密码不写入文件、不上传；私钥解锁后只在内存中临时使用，点「立即锁定」或关闭页面即从内存清除。

## 四、换电脑 / 恢复私钥备份

源码包里的私钥备份已加密为 `donate_priv.pem.enc`（同样用初始口令 `temp-bxq-2026` 加密）：

```bash
python3 解密工具.py donate_priv.pem.enc temp-bxq-2026 donate_priv.pem
```

（需 `pip install cryptography`）。解出的私钥与原私钥完全相同。

## 六、验证情况

- 网页版：浏览器实测「初始口令解锁 → 设自己密码 → 生成激活码」全流程通过，产出的码经 App 公钥 RSA-SHA256 验签通过。
- 安卓版：KeyBox 解密出的私钥与原私钥逐字节一致；改密码往返、错误口令拒绝、安卓加密包可被网页版解开，均通过。
- 生成器 APK 已签名；dex 中 `BEGIN PRIVATE KEY` / 私钥 Base64 前缀均为 0 处。
