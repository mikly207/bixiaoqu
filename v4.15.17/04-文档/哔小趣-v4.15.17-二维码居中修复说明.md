# 哔小趣 v4.15.17 · 二维码居中修复说明

## 一、为什么二维码跑到右下角还被裁掉

v4.15.16 是在**网页里**排版：往 B 站页面注入一个 `position:fixed; width:100%; height:100%` 的遮罩，再用 flex 居中。

问题在于 WebView 里有两套坐标：

- `fixed` 定位和百分比尺寸，参照的是**布局视口**（页面按 980/1200px 排版的那个）
- 你实际看到的是**可视视口**（手机窗口那一块）

两者不等宽时，遮罩的中心并不在屏幕中心。你的窗口比布局视口窄，于是“居中的卡片”落在了可视区右侧偏下 —— 还超出了容器边界被裁掉一半。换台机器、换个窗口大小，偏移量还会变。

**在网页里算位置这件事本身不可靠，所以这版不再在网页里排版。**

## 二、这版怎么做

网页只干一件事：**把官方页面里那张二维码图交出来**。

```
隐藏的 1px WebView（桌面 UA 打开 passport.bilibili.com/login）
   → 每 1.1 秒问一次：二维码图换了吗？
   → 变了就把图片的 base64（data:image/png;base64,...）交回来
   → 原生 Base64 解码成 Bitmap，塞进 ImageView
```

界面 100% 由原生控件画：

- `LinearLayout(vertical)` 三段：顶部标题／中间区域／底部按钮
- 中间区域是 `FrameLayout`，权重 1（占满剩余空间）
- 白卡用 `FrameLayout.LayoutParams(width=s, height=s)` + `gravity=CENTER` —— **居中由布局参数保证，不是靠算坐标**
- 布局回调里按中间区域的**实际宽高**再校正一次：`s = min(区域宽×0.88, 区域高×0.94, 820)`。分屏、悬浮窗、横屏、折叠屏，卡片都完整居中

所以二维码不会再偏，也不会被裁。

## 三、静区（扫码成功率的关键）

官网这张图本身是 **140×140** 的实体图，**四周没有留白**。扫码器靠白边（4 个模块宽）定位，白边不够就扫不出来。

这版把白卡内边距设为**边长的 7.5%**，二维码显示约 730px 时白边约 55px，正好 4 个模块宽；同时关掉 `BitmapDrawable` 的平滑过滤，放大用最近邻，边缘锐利不发虚。

（v4.15.16 你之所以能扫成功，就是因为它留了 8.5% 白边；这版保留同样的比例，只是改由原生控件画。）

## 四、顺手查清一个陈年 Bug

对比 dex 里的类，发现打包缺了两个：

```
com/google/zxing/qrcode/encoder/Encoder          -> 缺失
com/google/zxing/common/reedsolomon/ReedSolomonEncoder -> 缺失
```

`QRCodeWriter.encode()` 一执行就抛 `NoClassDefFoundError`。它是 `Error` 不是 `Exception`，旧代码 `catch (Exception)` 抓不住 —— 所以 v4.15.15 才会“链接取到了、图却出不来、屏幕一片白”。

这版**彻底不走 ZXing**，二维码内容直接来自官网页面；同时把 `makeQr` 的捕获范围改成 `Throwable`，旧的直连通道即使失败也不会再把线程打挂。

## 五、实测

| 检查项 | 结果 |

| 注入脚本取图 | `data:image/png;base64,iVBORw0KGgo…`，8002 字符，140×140 |
| 二次调用 | 返回 `same`（不重复传大字符串，只在换码时传） |

## 六、安装

- 版本：**v4.15.17（versionCode 113）**
- 签名不变（`0930aba7…`），**直接覆盖安装，不用卸载**
- 入口：`我的 → 登录 → 二维码登录`

打开后 1~2 秒，**二维码出现在屏幕正中间**（白卡 + 二维码，上下留白均衡）；扫完在手机上点「确认登录」，App 自动提示「登录成功 ✓ 昵称」。

底部三个按钮：`换一张`（重载拿新码）、`官方页面`（打开完整官网页，可改密码/短信登录）、`短信登录`。
