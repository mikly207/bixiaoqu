# 哔小趣 v4.42.0 直播实验版 · 直播间界面按 B 站原生重做

> 本次迭代**只围绕直播**，其它功能模块零改动。以你发的 B 站直播截图为参照，
> 把直播间播放界面从「标题栏 + 悬浮条」重做为接近 B 站原生的竖屏直播间：
> 主播栏、榜单标签、人气值、原生风格弹幕、底部互动栏、挂件一应俱全。
> 手机 / 平板双版本同步。

---

## 一、播放界面重做（核心）

对照你发的截图，播放态现在包含以下元素：

| 截图元素 | v4.42 实现 |
|---|---|
| 顶部返回 + 主播头像 + 昵称 + 点赞/粉丝 | 返回箭头 + **圆形主播头像**（真机异步加载 face，失败用昵称首字圆形占位）+ 昵称 + 粉丝数 |
| 粉色「关注」按钮 | 顶部 **+关注** 按钮，点击即变色为「已关注」，并真实调用关注接口，失败自动回滚 |
| 右上观众头像 + 人气值 | 三个彩色观众头像堆叠 + 实时人气值（房间在线数） |
| 「热门榜 / 人气榜」标签 | 顶部第二行榜单胶囊标签 |
| 房间号角标 | 左上角 `bilibili 直播 房间号` 半透明角标 |
| 带等级徽章的弹幕 | 弹幕改为**原生风格**：圆角等级徽章（按等级自动配色）+ 彩色用户名 + 白色正文 + 描边，舰队另有高亮色条 |
| 底部 ··· / 表情 / 燃 / 礼物 | 底部互动栏：更多、表情、**燃（点赞+1 带弹跳动画）**、礼物面板 |
| 弹幕输入框 + 发送 | 底部「弹幕支持下~」输入框 + 粉色发送按钮，真实调用发弹幕接口，本地立即上屏 |
| 右下挂件卡片 | 右下「直播小玩法 · 战力值」挂件卡片 |
| 画质 / 弹幕开关 | 顶部第二行保留画质切换与弹幕开关，功能不丢 |

画质切换、弹幕开关、返回、横竖屏切换等原有能力全部保留。

## 二、直播弹幕原生化

- `DanmakuView` 新增 `addLive(...)`：支持**用户等级徽章 + 彩色用户名 + 舰队标识**，
  等级按 B 站分段配色（蓝→绿→黄→橙→品红→粉）；原视频弹幕接口完全不动，播放页零影响。
- `LiveDanmakuClient` 解析 `DANMU_MSG` 时新增提取：用户等级、等级颜色、粉丝勋章、舰队等级，
  多位置容错（B 站字段位置会随版本变动），通过 `onDanmakuRich` 回调给弹幕层。
- 演示模式弹幕也换成带等级/用户名的样式，观感统一。

---

## 三、互动功能（本次新增）

- `BiliApi` 新增并双版同步：
  - `liveSendDanmaku` 发送直播弹幕（需登录，失败提示）
  - `liveLike` 直播间点赞
  - `liveRoomDetail` 直播间详情（头像 / 粉丝数 / uid）
  - `liveUserInfo` 主播信息
- 关注复用现有 `modifyFollow`，未开播 / 风控时均有本地反馈与失败回滚，不卡界面。

---

## 四、稳定性：v4.41 修复全部保留

卡死修复链条一行没动：线程池扩容 + 有界队列、代际隔离（旧连接 410）、
分片 25s 熔断、有限重连（最多 3 次）、accept 守护线程、多线路择优 + 亲和 + m3u8 短缓存、
演示模式兜底。退出再进、快速连点房间等场景依旧稳定。
